# 用户偏好与写作规范（AI 地陪）

> 本文件记录用户在旅行规划中的偏好和习惯，启动时读取，确保输出风格一致。

## ⚠️ 重要免责声明

- **常驻位置（南昌九龙湖）仅用于判断出行出发地**，不用于目的地推荐或美食搜索
- 在旅游规划中，"本地" = 目的地城市，**不是**南昌
- 搜索"本地美食"时，query 必须包含目的地城市名，禁止默认使用南昌
- **本文件中任何与南昌相关的信息在旅行规划上下文中均不适用**

## 旅行风格偏好

| 维度 | 用户偏好 | 说明 |
|------|----------|------|
| 节奏 | **慢节奏** | 每天一个片区即可，拒绝特种兵式打卡 |
| 重点 | **逛吃逛吃 + 拍照出片** | 美食和摄影是同等重要的核心需求，景点只是散步的理由 |
| 住宿 | **玉林/倪家桥片区**（本地）/ **台东/五四广场**（青岛等旅游城市） | 本地生活气息浓，不是景区但比景区更像本地 |
| 住宿（多人出行） | **同性朋友默认合住一间，情侣100%合住** | 不需要问"要不要分开住"，按一间房算预算；除非用户主动提分开住 |
| 拍照偏好 | **生活照/随拍** | 不拍写真，随走随拍；不是摄影旅拍。Pose：牵手背影、回眸、比ye、靠墙侧脸、逆光剪影 |
| 海边活动 | **不游泳，只海边散步/踩水/拍照** | 不安排游泳、不下海、不推荐泳衣 |
| 夜生活 | **轻度**（晚上逛逛吃东西可以，不蹦迪不夜店） | 22:00前回即可 |
| 年龄层 | **00后-10后** 女生 | 风格偏自然/生活化/日系/法式/胶片 |
| 忌口 | **暂无** | 用户确认无忌口/过敏 |
| 出发地 | 萍乡（江西） | 近期从萍乡出发跟团游 |
| 年龄层 | **年轻人** | 默认假设年轻人，攻略要有活力 |

## 文案输出偏好

| 维度 | 用户偏好 | 反例 |
|------|----------|------|
| 语言 | 中文为主，emoji适度 | 满屏emoji或纯文字都不好 |
| 推荐风格 | **给明确推荐 + 理由** | "推荐xxx"而不说为什么 ❌ |
| 店铺名 | **用"推荐的店"** | 比"本地人常去的店"更中性准确 |
| 地址标注 | "建议出发前用高德确认" | 直接给地址不加提示 ❌ |
| 语气 | 像本地朋友，不像导游/客服 | 官方介绍腔 ❌ |
| 结构 | 表格+列表+分段，信息密度适中 | 大段文字 ❌ |
| 预算 | 必须标注，越细越好 | 笼统说"人均XXX" ❌ |

## 避坑偏好

用户主动提及或确认过需要避开的坑：

- 景区内东西贵，只逛不买
- 社区店比连锁网红正宗
- 不能吃辣提前说，别硬撑
- 城隍庙小吃城又贵又一般，只逛不买
- 外婆红烧肉/糖醋排骨是甜口，跳过换川菜
- 王家沙蝴蝶酥是甜的，尝一个可以别多吃
- 陆家嘴登高选金茂88层（¥120）比上海中心（¥180）性价比高
- 武康路扎堆，上午10点前或下午4点后去
- 西湖龙井茶村买茶价格水分大，喝茶即可
