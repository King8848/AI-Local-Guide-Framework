# 数据来源标注规范（AI Local Friend）

> 最后更新：2026-07-23 · 用户要求：每个推荐必须标注数据来源

## 规则

**所有推荐类输出（酒店/景点/美食/停车）必须标注数据来源**。

### 标注格式

```markdown
### 🔍 [数据源名称] 推荐

> 数据来源：[具体说明]

| 项目 | ... | 来源 |
|------|-----|------|
| XXX  | ... | 高德 API / FlyAI / 携程 / 知识库 |
```

### 多源对比时

当多个数据源都有结果时，按以下优先级排列：
1. **FlyAI**（飞猪实时数据）— 有预订链接时优先
2. **高德地图 API**（POI 数据）— 评分、坐标、电话、照片
3. **携程/美团**（价格参考）— 实时价格需用户自行确认
4. **知识库**（兜底）— 无实时数据时使用

### 价格标注规范

- FlyAI 返回的价格 → 标注"飞猪价"
- 高德 API 无价格 → 标注"参考价（携程/美团）"
- 知识库价格 → 标注"参考价（可能过时）"
- 所有价格加注"建议出发前确认实际价格"

## 数据源质量速查

| 数据源 | 酒店 | 景点 | 美食 | 停车 | 交通 |
|--------|------|------|------|------|------|
| FlyAI | ⚠️ 中档断层 | ✅ | ❌ 返酒店商品 | ❌ | ✅ 机票/火车票 |
| 高德 API | ✅ 无价格 | ✅ | ✅ | ✅ | ✅ |
| Serper | ✅ 价格参考 | ✅ | ✅ | ✅ | ✅ |
| 知识库 | ⚠️ 过时 | ✅ | ✅ | ⚠️ | ⚠️ |
