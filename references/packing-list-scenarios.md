# 行李清单场景化模板

> 根据出行方式（自驾/高铁/飞机）+ 天气 + 活动生成个性化行李清单

---

## 📋 信息收集清单

| 问题 | 为什么必须问 | 示例 |
|------|-------------|------|
| 出行方式 | 决定能带什么 | 自驾（可以多带）/ 高铁（轻装）/ 飞机（限重） |
| 出行天数 | 决定带多少 | 3 天 2 晚 |
| 目的地天气 | 决定带什么衣服 | 33°C 阴天 |
| 特殊活动 | 额外物品 | 演唱会、海边、登山 |
| 拍摄设备 | 充电/存储 | Pocket 3、手机 |
| 住宿类型 | 洗漱用品 | 酒店（有）/ 民宿（可能没有） |

---

## 🚗 自驾清单（最全）

### 必带

| 物品 | 说明 |
|------|------|
| 身份证 | 入住+活动入场 |
| 驾驶证 | 自驾必须 |
| 手机+充电线 | 导航+支付 |
| 充电宝 | ≥10000mAh |
| 钱包/卡 | ETC、加油卡 |
| 雨伞 | 看天气 |

### 拍摄设备

| 物品 | 说明 |
|------|------|
| 相机（Pocket 3 等） | 主力拍摄 |
| 充电线/充电头 | 支持边充边拍 |
| SD 卡（≥64GB） | 4K 约 1GB/3 分钟 |
| 三脚架（小型） | 延时/合照 |
| 擦镜布 | 雨天/灰尘 |

### 生活用品

| 物品 | 说明 |
|------|------|
| 换洗衣物 | 按天数+1 套 |
| 薄外套 | 地铁/商场空调 |
| 防晒霜 | 阴天紫外线也强 |
| 帽子+墨镜 | 防晒+拍照道具 |
| 湿巾/纸巾 | 擦汗 |
| 小零食 | 车上吃 |
| 水杯 | 补水 |
| 舒适的鞋 | 全天步行 |
| 洗漱用品 | 酒店可能有，但自带更卫生 |
| 常用药 | 肠胃药、创可贴、防蚊液 |

### 车载

| 物品 | 说明 |
|------|------|
| 车载充电器 | 手机导航很费电 |
| 车载手机支架 | 导航用 |
| 现金少量 | 停车费/过路费 |
| 矿泉水 | 车上备几瓶 |

| 身份证 | 进站+入住 |

### 拍摄设备

| 物品 | 说明 |
|------|------|

| SD 卡 | — |

### 生活用品

| 物品 | 说明 |
|------|------|

| 防晒霜 | 小瓶装 |
| 舒适的鞋 | 穿脚上，不占行李空间 |

## ✈️ 飞机清单（限重）

### 必带（随身）

| 物品 | 说明 |
|------|------|
| 身份证/护照 | 必须 |
| 手机+充电线 | — |
| 充电宝（≤20000mAh） | 必须随身，不能托运 |

### 拍摄设备（随身）

| 物品 | 说明 |
|------|------|
| 相机 | 随身携带，不能托运 |
| 充电线 | — |
| SD 卡 | — |

### 托运行李

| 物品 | 说明 |
|------|------|
| 换洗衣物 | 压缩袋 |
| 洗漱用品 | ≤100ml/瓶，装透明袋 |
| 防晒霜 | ≤100ml |
| 常用药 | — |

**注意**：
- 充电宝必须随身，不能托运
- 液体单瓶 ≤100ml，总量 ≤1L
- 相机/镜头随身携带
