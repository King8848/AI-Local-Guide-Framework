# 拍照需求处理模式（P-002）

> **触发条件**：用户提到"拍照"、"出片"、"写真"等关键词
> **适用场景**：旅行规划中的拍照需求处理
> **状态**：🟢 已验证 2026-07-19

## 核心原则

**摄影是和美食、游玩同等重要的核心需求**，不能事后补充。
必须在规划阶段就作为独立维度嵌入：每天至少规划 1-2 个出片点位，精确到**几点去、穿什么、怎么摆 pose**。
如果行程写完发现没提拍照，说明规划失败了。

## 5 步标准流程

### Step 1: 识别拍照风格

| 关键词 | 风格 | 代表点位 |
|--------|------|---------|
| "日系"、"胶片"、"小清新" | 日系胶片 | 八大关、小麦岛、琴屿飘灯 |
| "法式"、"文艺"、"复古" | 法式复古 | 大学路、黄岛路、良友书坊 |
| "大气"、"男友视角" | 大气海景 | 石老人、金沙滩、仰口 |
| "烟火气"、"夜市" | 人间烟火 | 台东、营口路、李村 |
| "情绪片"、"孤独感" | 情绪片 | 小麦岛孤独的树、石老人礁石 |
| "不拍写真"、"随拍" | 生活化抓拍 | 牵手背影、回眸、比ye、靠墙侧脸 |

### Step 2: 匹配出片点位（精确到时段）

| 点位 | 最佳时段 | 风格 |
|------|---------|------|
| 居庸关路（八大关） | 6:00-8:00 晨光 | 日系/法式 |
| 鱼山路/大学路交叉口 | 7:00-9:00 / 16:00-18:00 | 文艺红墙 |
| 信号山旋转观景台 | 日落前1h | 城市俯瞰 |
| 小麦岛孤独的树 | 日落前2h | 孤独感/情绪片 |
| 第二海水浴场堤坝 | 16:00-18:00 黄金光 | 胶片/文艺 |
| 小青岛灯塔 | 5:30-7:00 清晨 | 日系/灯塔 |
| 栈桥回澜阁 | 6:30-7:30 人少时 | 经典地标 |
| 石老人礁石海滩 | 退潮时 / 日落 | 大气/男友视角 |
| 11号线地铁 | 任意时段 | 日系/千与千寻 |
| 良友书坊 | 有阳光的下午 | 复古/文艺 |
| 五四广场「五月的风」 | 晚上8点开灯后 | 城市夜景 |

### Step 3: 穿搭建议

| 类别 | 推荐 | 原因 |
|------|------|------|
| 裙子 | 白色棉麻长裙 / 碎花法式裙 | 海边+红墙+绿树万能搭 |
| 上衣 | 浅色亚麻衬衫 / 露背背心 | 青岛八月热但不闷热 |
| 帽子 | 草帽 / 渔夫帽 | 防晒+造型两不误 |
| 道具 | 花束、草编包、透明伞、奶茶杯 | 手不知道往哪放时的神器 |
| 鞋 | 平底凉鞋 / 帆布鞋 | 老城有坡，高跟鞋会哭 |

### Step 4: Pose 细化（按风格）

**生活化抓拍（默认，用户说"不拍写真"时）：**

| 场景 | Pose |
|------|------|
| 海边 | 背对镜头牵手走、裙摆被风吹起瞬间、坐在礁石上只拍背影 |
| 八大关 | 假装走楼梯被叫住回头、在花丛中探头、撑透明伞站在路中间 |
| 红墙 | 靠在墙上对视、用手指比心、一人假装路过 |
| 小麦岛 | 孤独的树旁边一人站一边、蹲在草坪上对视笑、逆光剪影 |
| 地铁 | 11号线穿过山峦时抓拍窗外、站在车厢连接处动态抓拍 |
| 夜市 | 吃东西的侧脸、举杯干杯、街灯下的回眸 |

**注意**：不要建议商业写真的"托腮看镜头""侧卧露出腰部"等摆拍。

### Step 5: 融入 Day-by-Day 行程

**不是独立附录**，必须和每天的行程一一对应：

```
❌ 错误：
Day 2: 上午 → 信号山公园
      下午 → 大学路
      晚上 → 中山路
（拍照只是独立附录，和行程无关）

✅ 正确：
Day 2: 上午 7:00-9:00 → 红墙大学路（避开人流高峰）
       📸 Pose: 一人靠在红墙上，另一人拍侧面
       上午 10:00 → 信号山公园
       📸 观景台互相拍"背影看海"
       下午 4:00-6:00 → 大学路第二遍（黄金光）
       📸 补漏上午没拍完的街景
```

## 按年龄层细化（00后-10后女生）

- 风格偏好：自然/生活化，明确排斥商业写真
- Pose 建议：牵手背影、回眸、比ye、靠墙侧脸、逆光剪影
- 穿搭建议：棉麻/碎花/草帽等日系/法式元素
- 禁止建议："托腮看镜头""侧卧露出腰部"等摆拍
