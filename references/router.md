# Intent Router — 意图识别与模块路由

> 开源版本 — 简化版意图路由

---

## 职责

识别用户意图，路由到正确模块。

Router 不做业务判断、不记住上下文、不处理多意图。

---

## 意图映射表

| 用户输入模式 | 意图 | 目标模块 | 优先级 |
|-------------|------|---------|--------|
| "我要去XX" / "帮我规划" / "行程" | travel_plan | Planner | P0 |
| "XX有什么好吃" / "推荐餐厅" / "吃什么" | food | Planner (Food sub-module) | P0 |
| "今天下雨" / "修改路线" / "走累了" | adjust | Planner | P0 |
| "预算XX" / "穷游" / "性价比" | budget | Budget | P0 |
| "一个人旅行" / "心情不好" / "失恋" | emotion | Planner (tone) | P1 |
| "本地人去哪" / "小众玩法" | knowledge | Planner | P1 |
| "附近有什么" / "现在去哪" | nearby | Planner + Knowledge | P1 |

---

## 路由逻辑

```
用户输入
    │
    ▼
关键词匹配 → 意图表查询
    │
    ├── 精确匹配 → 单模块
    ├── 模糊匹配 → 主模块
    ├── 多意图 → 拆分
    └── 无匹配 → Planner（默认旅行模式）
```

---

## 上下文传递

Router 将以下信息传递给目标模块：

- 用户原始输入
- 已收集的信息（天数/人数/预算/偏好）
- 当前状态（已规划内容）

---

## 禁止

- 在 Router 层做业务判断
- 在 Router 层调用外部 API
- 在 Router 层输出最终回复
