# 自驾出行规划参考（AI 地陪）

> 情侣/朋友自驾到目的地城市的规划模式，适用于周末短途（2-3天）自驾游。

---

## 自驾基础信息模板

每次自驾出行，必须主动计算并展示以下信息：

| 项目 | 计算方式 |
|------|---------|
| 距离/时间 | 高德/百度导航确认，展示单程 |
| 高速费 | 小型车 0.45 元/km（全国标准），粗算即可 |
| 油费 | 公式：`距离(km) × 百公里油耗(L) / 100 × 油价(元/L)`，默认按 8L/100km、油价 7.5 元估算 |
| 往返总计 | 高速费×2 + 油费×2 |

---

## 停车策略（核心）

自驾游的停车问题是用户最关心的痛点之一。每个涉及的地点都必须给出停车方案。

### 住宿停车

| 策略 | 说明 |
|------|------|
| **优先选有免费车位的酒店** | 入住前确认，这是选酒店的重要因素 |
| 酒店地库 = 大本营 | 到达后车停酒店，市内出行改地铁/步行 |
| 演唱会/大型活动日 | 车停酒店不动，地铁去场馆（避免散场堵车+找车） |

### 景点停车

- 每个景点单独列出推荐停车场 + 费用 + 步行距离
- 周末景区停车紧张，建议早到或选备选停车场
- 古城区巷子窄（如陶谷新村、颐和路），车停外圈走进去

### 换乘停车（大城市）

如果目的地是大城市核心区（南京/杭州/上海等），提供「边缘停车+地铁进城」方案：
- 城市边缘地铁站换乘停车场（如南京的马群站、油坊桥站）
- 停车费低廉甚至免费
- 换地铁进城，避免市区堵车+高额停车费

## 路线规划原则

| 原则 | 说明 |
|------|------|
| **上午郊区开车，下午城区步行** | 早上精力充沛适合开远路，下午累了就近逛 |
| **先远后近** | 把最远的点放第一个，回程顺路经过近的点 |
| **单向不回头** | 路线设计成环形或单向，不走回头路 |
| **停车场 = 中转站** | 每到一个片区停一次车，步行逛完再开车去下一片区 |

### 一日自驾路线模板

```
酒店(出发) → 远郊景点(30-60min车程) → 午餐(当地) → 城区景点群(步行) → 晚餐 → 返程/回酒店
```

---

## 夜间驾驶安全

返程如果是夜间驾驶（20:00后出发），必须提醒：

1. **中途至少停一次服务区休息 15-20 分钟**
2. 开远光灯切换提醒（高速用远光，遇车切近光）
3. 疲劳驾驶比超速更危险——困了就停，不要硬撑
4. 预估到达时间要加 30 分钟缓冲

---

## 演唱会/活动停车专项

| 阶段 | 策略 |
|------|------|
| 到达当天 | 车停酒店，地铁/步行去场馆 |
| 散场 | 地铁末班车时间必须提前查（如南京10号线 23:22） |
| 散场打车 | 提前叫车，场馆周边打车排队 30-60 分钟 |
| 第二天 | 如有活动，重复上述策略 |

## 预算模板

自驾游预算必须包含以下项目：

| 项目 | 说明 |
|------|------|
| 高速费（往返） | 必算 |
| 油费（往返） | 必算 |
| 住宿 | 含停车费 |
| 景点门票 | 免费的也要标注"免费" |
| 停车费（景点） | 按景点列 |
| 餐饮 | 按天估算 |
| 备用金 | 200-300 元 |
