# 雨天备案标准模板

> 每次规划行程时，必须同时生成雨天备案。规则：每个户外点位必须有一个室内替代方案。

---

## 📋 信息收集清单

| 问题 | 为什么必须问 | 示例 |
|------|-------------|------|
| 目的地城市 | 查该城市的室内景点 | 南京 |
| 游玩天数 | 需要几个备案 | 1 天 |
| 已规划的户外点位 | 逐一替换 | 汤山矿坑公园、颐和路、鸡鸣寺城墙 |
| 是否接受"雨中拍" | 有些场景雨中更有味道 | 颐和路雨中可以 |

---

## 🌧 备案生成规则

### 规则 1：户外 → 室内替换

| 户外类型 | 室内替代方向 | 举例 |
|---------|-------------|------|
| 公园/山/湖 | 博物馆/美术馆 | 玄武湖 → 南京博物院 |
| 老街/巷子 | 咖啡店/书店 | 陶谷新村 → 先锋书店 |
| 城墙/古建 | 室内展馆 | 鸡鸣寺城墙 → 总统府 |
| 郊区景点 | 市区室内 | 汤山矿坑 → 南京博物院 |

### 规则 2：部分场景雨中更好

| 场景 | 雨中效果 | 建议 |
|------|---------|------|
| 梧桐大道 | 雨滴+倒影+民国味 | ✅ 带伞拍 |
| 老街石板路 | 湿润反光+氛围感 | ✅ 带伞拍 |
| 荷花池 | 雨打荷叶 | ✅ 带伞拍 |
| 玻璃窗咖啡店 | 雨滴+窗内温暖 | ✅ 坐窗边拍 |

### 规则 3：保留室内点位

以下点位不受雨天影响：
- 先锋书店（室内）
- 博物馆/美术馆（室内）
- 咖啡店/餐厅（室内）
- 商场/文创园（室内）

---

## 📝 备案输出格式

```
## 🌧 雨天备案

> [日期]预报[天气]，但如果突降暴雨：

| 原计划 | 雨天替代 |
|--------|---------|
| [户外点位1]（户外） | 改为[室内替代1]（室内，[理由]） |
| [户外点位2]（户外） | 雨中更有味道，带伞拍！ |
| [室内点位]（室内） | 不受影响 |

**雨天拍摄技巧**：
- 雨滴打在伞上的声音收音很好听
- 地面倒影拍出来很有氛围感
- 雨中的[特色场景]比晴天更有味道
```

## ⚠️ 雨天出行提醒

| 项目 | 提醒 |
|------|------|
| 自驾 | 降速、开雾灯、保持车距、避免急刹 |
| 步行 | 穿防滑鞋、带伞、避开积水 |
| 拍摄 | Pocket 3 防水溅但不防水浸，带擦镜布 |
| 停车 | 雨天停车费不变，但找车位更难 |
| 天气查询 | 出发前 1 小时再查一次，天气可能变化 |
