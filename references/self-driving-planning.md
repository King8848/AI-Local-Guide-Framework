# 自驾旅行规划补充指南

> 与公共交通不同，自驾游有独特的规划维度：停车、油费、高速费、返程疲劳。

## 自驾特有规划项

### 1. 停车规划

**必须在规划阶段就确认每个景点的停车方案**，不是到了再找。

| 场景 | 停车策略 |
|------|---------|
| 住宿酒店 | 优先选有免费停车的，这是自驾酒店的硬性条件 |
| 市区景点 | 提前查周边停车场（高德 around API: types=150900） |
| 郊区景点 | 通常有免费大型停车场（矿坑公园、植物园等） |
| 演唱会/大型活动 | 车停酒店，地铁/打车去现场。散场停车场出不去 |
| 吃饭 | 选有停车位的餐厅，或商场停车场（消费免费停） |

**查询方式**：高德 API 周边搜索
```
/v3/place/around?location=经度,纬度&keywords=停车场&radius=2000&types=150900
```

### 2. 费用计算

| 项目 | 计算方式 |
|------|---------|
| 高速费 | 小型车约 ¥0.45/km，单程距离×0.45 |
| 油费 | 距离÷100×油耗(L/100km)×油价 |
| 停车费 | 市区 ¥6/小时，景区 ¥10/次 或免费 |
| 过路费查询 | 高德导航规划时会显示 |

### 3. 路线规划

- 去程走高速，确认沿途服务区（休息+加油）
- 返程如果晚于 22:00，注意疲劳驾驶，中途至少停一次
- 市内导航用高德，提前下载离线地图

### 4. 自驾 vs 打车的决策

| 场景 | 建议 |
|------|------|
| 住宿→郊区景点（20km+） | 开车 |
| 市区内多个景点串联 | 看停车难度。停车方便→开车；老城区→地铁+打车 |
| 晚上吃饭/夜市 | 打车或地铁（喝酒不开车） |
| 演唱会/大型活动 | 不开车，散场堵死 |

## 自驾行程模板

```
Day 1: 出发地 → 目的地（高速）
  - 出发前加满油
  - 中途服务区休息一次
  - 到达后停酒店，步行/打车去活动

Day 2: 市区活动
  - 近距离：步行/地铁
  - 远距离：开车（提前查停车场）

Day 3: 郊区 + 返程
  - 上午去郊区景点（开车）
  - 午餐后返程
  - 返程前加满油
  - 预估到达时间，太晚就中途服务区休息
```

## 住宿选择（自驾特有条件）

**硬性条件**：
1. ✅ 免费停车（或停车费 ≤ ¥20/天）
2. ✅ 停车位充足（不是只有3个车位的小旅馆）
3. ✅ 靠近高速入口或主要道路（不堵车）

**加分项**：
- 有充电桩（电动车）
- 周边有加油站
- 离第二天景点近（减少早上通勤）

## 常见坑

| 坑 | 教训 |
|------|------|
| 老城区开车 | 单行道多、停车难、限行。老城区景点优先地铁/步行 |
| 演唱会散场 | 停车场出口堵 30-60 分钟。车停酒店打车去 |
| 高速返程疲劳 | 4小时以上的夜驾必须中途休息，别硬撑 |
| 景区停车涨价 | 节假日景区停车场可能涨价或满员，提前查 |
| 导航不准 | 建议出发前用高德确认地址，不要到了再搜 |
