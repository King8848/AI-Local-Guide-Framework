# 高速服务区自动规划模板

> 自驾行程必须包含服务区规划。规则：每 2 小时或 200km 必须休息一次。

---

## 📋 信息收集清单

| 问题 | 为什么必须问 | 示例 |
|------|-------------|------|
| 出发城市 | 规划路线起点 | 义乌 |
| 目的地城市 | 规划路线终点 | 南京 |
| 驾驶时长 | 决定休息次数 | 4.5 小时 |
| 到家时间上限 | 反推返程出发时间 | 不超过 24:00 |

---

## 🛣 服务区规划规则

### 规则 1：休息频率

| 驾驶时长 | 休息次数 | 休息时长 |
|---------|---------|---------|
| ≤2 小时 | 0 次 | — |
| 2-3 小时 | 1 次 | 10-15 分钟 |
| 3-4 小时 | 1-2 次 | 10-15 分钟/次 |
| 4-5 小时 | 2 次 | 10-15 分钟/次 |
| 5+ 小时 | 2-3 次 | 15-20 分钟/次 |

### 规则 2：休息时间点

| 段 | 建议休息点 | 说明 |
|----|-----------|------|
| 第 1 段 | 1.5-2 小时后 | 第一次休息，上厕所+活动 |
| 第 2 段 | 3-3.5 小时后 | 第二次休息，补水+吃东西 |
| 第 3 段 | 4.5-5 小时后 | 第三次休息（长途） |

### 规则 3：服务区选择

| 优先级 | 条件 | 原因 |
|--------|------|------|
| 1 | 大型服务区 | 设施齐全（餐饮/便利店/厕所/加油） |
| 2 | 有餐饮的服务区 | 中途可以吃饭 |
| 3 | 有加油站的服务区 | 补油 |
| 4 | 任何服务区 | 至少可以上厕所 |

## 🗺 服务区查询方法

### 方法 1：高德 API

```
GET https://restapi.amap.com/v3/place/around
  ?key={API_KEY}
  &location={经度},{纬度}
  &keywords=服务区
  &radius=50000
  &types=交通设施服务
```

### 方法 2：高德地图 APP

1. 打开高德地图
2. 搜索"服务区"
3. 选择路线上的服务区

### 方法 3：百度搜索

搜索"[出发地]到[目的地] 高速服务区 推荐"

## ⚠️ 自驾安全提醒

| 项目 | 提醒 |
|------|------|
| 疲劳驾驶 | 每 2 小时休息一次，困了立即停车 |
| 夜间驾驶 | 降速、开远光灯（无对向车时）、更频繁休息 |
| 雨天驾驶 | 降速、开雾灯、保持车距、避免急刹 |
| 高温天气 | 检查胎压、备水、避免疲劳 |
| 长途驾驶 | 出发前检查油量/胎压/刹车/灯光 |
| ETC | 确保 ETC 正常，备少量现金 |
