## 🎬 通用运镜技巧（设备无关）

### 基础运镜

| 运镜 | 适用场景 | 要领 |
|------|---------|------|
| **固定机位** | 风景延时、人物特写 | 三脚架/放平，不动 |
| **缓慢平移** | 全景扫描、涂鸦墙 | 手臂伸直，腰部以上转动 |
| **推进** | 从远到近，突出主体 | 匀速前进，保持水平 |
| **穿越** | 窄巷、书架、门洞 | 低角度，gimbal 保持水平 |
| **跟拍** | 人物行走 | ActiveTrack 或手动跟踪 |
| **环绕** | 建筑、雕塑 | 绕物体走半圈/一圈 |
| **仰拍** | 高建筑、天花板 | 手机/相机朝上，缓慢推进 |
| **俯拍** | 台阶、人群 | 高处往下拍 |

### 进阶运镜

| 运镜 | 适用场景 | 要领 |
|------|---------|------|
| **推拉结合** | 建筑入口 | 先推进再拉远，一镜到底 |
| **旋转推进** | 螺旋楼梯、书架 | 边旋转边前进 |
| **延迟跟随** | 人物走过长廊 | 人物先走，镜头慢半拍跟上 |
| **前景遮挡** | 栏杆、树叶、门框 | 从遮挡物后方露出主体 |

## 📍 按场景分类的拍法

### 🏙 街巷/老街

| 点位类型 | 推荐运镜 | Pocket 3 技巧 | 手机技巧 |
|---------|---------|--------------|---------|
| 窄巷 | 穿越运镜 | 低角度 gimbal 水平 | 用稳定器或双手持 |
| 老墙/涂鸦 | 缓慢平移 | 从左到右扫过 | 同上 |
| 石板路 | 跟拍行走 | ActiveTrack | 手动跟踪 |
| 门口/门洞 | 推进运镜 | 从门外推到门内 | 同上 |

**构图要点**：
- 利用巷子的纵深感做引导线
- 人物放在画面 1/3 处
- 逆光拍剪影，顺光拍细节

### 🏛 建筑/历史景点

| 点位类型 | 推荐运镜 | Pocket 3 技巧 | 手机技巧 |
|---------|---------|--------------|---------|
| 大门/牌坊 | 仰拍推进 | 从远处推进到门下 | 同上 |
| 殿堂内部 | 固定机位 | 放在栏杆上拍全景 | 同上 |
| 柱子/走廊 | 穿越运镜 | 沿走廊低角度穿行 | 同上 |
| 屋顶/飞檐 | 仰拍缓慢上摇 | 从底部上摇到屋顶 | 同上 |

**构图要点**：
- 利用建筑对称性
- 框架构图（门框、窗框、柱子）
- 仰拍显气势，俯拍显规模

### 🌿 自然/公园

| 点位类型 | 推荐运镜 | Pocket 3 技巧 | 手机技巧 |
|---------|---------|--------------|---------|
| 湖面/水面 | 固定机位延时 | 间隔 2s，拍 5-10 分钟 | 同上 |
| 树荫小道 | 跟拍行走 | ActiveTrack | 手动跟踪 |
| 花丛/草地 | 低角度推进 | 贴近地面推进 | 同上 |
| 山顶/观景台 | 全景缓慢平移 | 从左到右扫全景 | 同上 |

**构图要点**：
- 利用前景（树枝、花）做层次
- 水面倒影对称构图
- 延时拍云层流动

### 🍜 美食/餐厅

| 点位类型 | 推荐运镜 | Pocket 3 技巧 | 手机技巧 |
|---------|---------|--------------|---------|
| 菜品上桌 | 缓慢推进 | 从远景推到特写 | 同上 |
| 烹饪过程 | 固定机位 | 放在灶台旁边拍 | 同上 |
| 吃饭表情 | 自拍模式 | 旋转屏幕自拍 | 前置摄像头 |
| 街头小吃 | 跟拍 | 拍摊位+食物+人物 | 同上 |

**构图要点**：
- 45 度俯拍食物最诱人
- 蒸汽/热气用逆光拍
- 人物表情用自拍模式

### 🌙 夜景

| 点位类型 | 推荐运镜 | Pocket 3 技巧 | 手机技巧 |
|---------|---------|--------------|---------|
| 灯笼/霓虹 | 缓慢上摇 | 从灯笼特写上摇到全景 | 同上 |
| 夜市 | 穿越运镜 | 低角度穿行人群 | 同上 |
| 城市天际线 | 固定机位延时 | 车流光轨 | 长曝光模式 |
| 倒影 | 固定机位 | 水面/地面倒影 | 同上 |

**Pocket 3 夜景优势**：1 英寸底 + f/1.8，暗光表现好，ISO 可以开高

## 📷 拍照模式速查

| 模式 | 适用场景 | 操作要点 |
|------|---------|---------|
| **普通拍照** | 两人合照 | 定时 3 秒 / 语音控制 |
| **全景模式** | 大场景 | 横向缓慢转动，保持水平 |
| **延时摄影** | 云层/人流/日落 | 固定机位，间隔 2-5s |
| **运动延时** | 边走边拍 | 走路时拍摄，后期加速 |
| **慢动作** | 水滴/树叶/风吹 | 1080P 120fps |
| **HDR** | 逆光场景 | 自动合成多张 |

| 内容 | 建议时长 | 节奏 |
|------|---------|------|
| 单个景点 | 15-30 秒 | 快切 |

| 风格 | 适用场景 | 调色要点 |
|------|---------|---------|
| 日系清新 | 文艺街区、咖啡店 | 降对比、提亮度、偏青 |

| 鲜艳 | 美食、花丛 | 提饱和、提对比 |

## ⚠️ 常见拍摄坑

| 坑 | 预防 |
|----|------|
| 电池不够 | 带充电宝，支持边充边拍 |
| 存储卡满 | 4K 约 1GB/3 分钟，带 ≥64GB SD 卡 |
| 手抖 | 用 gimbal / 稳定器 / 靠墙 |
| 逆光人脸黑 | 用点测光对准面部 |
| 延时太短 | 至少拍 5 分钟，间隔 2s |
| 穿越运镜撞墙 | 提前走一遍路线 |
| 夜景噪点高 | Pocket 3 的 1 英寸底优势，手机用夜景模式 |
| 忘记拍合照 | 定时 3 秒 / 语音控制 / 请路人帮忙 |
