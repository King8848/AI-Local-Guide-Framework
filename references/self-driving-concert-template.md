# 自驾 + 活动（演唱会/音乐节/赛事）组合规划模板

> 适用场景：自驾出行 + 特定活动（演唱会/音乐节/体育赛事/展览）+ 周边游玩

---

## 📋 信息收集清单（必须先问）

### 出行基本信息

| 问题 | 为什么必须问 | 示例 |
|------|-------------|------|
| 出发城市 | 规划路线+距离+高速费 | 义乌 |
| 目的地城市 | 所有规划的锚点 | 南京 |
| 出行人数 | 住宿+预算 | 2人（情侣） |
| 出发时间 | 规划到达时间 | 周五 18:00 |
| 返程时间上限 | 反推行程截止时间 | 不超过 24:00 到家 |

### 活动信息

| 问题 | 为什么必须问 | 示例 |
|------|-------------|------|
| 活动类型 | 决定当天安排 | 演唱会 |
| 活动日期+时间 | 规划当天行程 | 周五 19:30、周六 14:00 |
| 活动地点 | 住宿选址+停车规划 | 奥体中心 |
| 是否多场 | 决定哪些天可用 | 周五+周六两场 |

### 住宿偏好

| 问题 | 为什么必须问 | 示例 |
|------|-------------|------|
| 预算区间 | 筛选酒店 | ¥100-180/晚 |
| 住宿天数 | 计算总费用 | 2晚 |
| 偏好类型 | 酒店/民宿/公寓 | 新一些的酒店 |
| 必须条件 | 自驾必须免费停车 | 免费停车 |

### 游玩偏好

| 问题 | 为什么必须问 | 示例 |
|------|-------------|------|
| 游玩重点 | 排序行程 | 拍照打卡 > 美食 > 景点 |
| 避免什么 | 排除选项 | 不要商业化太严重的景区 |
| 节奏偏好 | 控制行程密度 | 慢节奏 |
| 拍照设备 | 配套拍摄指南 | Pocket 3 |
| 特殊需求 | 补充信息 | 女生喜欢拍照 |

## 🗺 规划流程

### Step 1：锚定时间线

```
出发时间 → 到达时间 → 活动时间 → 可用游玩时间 → 返程时间
```

**示例**：
- 周五 18:00 出发 → 22:30 到达 → 入住+演唱会
- 周六：休息日（用户自行安排）
- 周日 09:00-18:00 可用 → 18:00 返程 → 22:30 到家

### Step 2：确定可用游玩天数

| 情况 | 可用天数 | 规划策略 |
|------|---------|---------|
| 活动当天到达 | 0 天 | 当天只安排活动 |
| 活动后有 1 天 | 1 天 | 集中规划 1 天精华路线 |
| 活动后有 2+ 天 | 2+ 天 | 每天一个片区，慢节奏 |

### Step 3：规划游玩日行程

**1 天行程模板**：

| 时间段 | 安排 | 原则 |
|--------|------|------|
| 09:00-12:00 | 上午片区（离住地远的） | 趁凉快去户外 |
| 12:00-13:30 | 午餐 | 当地特色 |
| 13:30-17:00 | 下午片区（离住地近的） | 避开最热时段选室内 |
| 17:00-18:00 | 晚餐/收尾 | 返程前吃饱 |
| 18:00+ | 返程 | 预留充足时间 |

**2 天行程模板**：

| 天 | 主题 | 选片逻辑 |
|----|------|---------|
| D1 | 文艺/历史 | 老城区、历史街区、书店、博物馆 |
| D2 | 自然/小众 | 郊区公园、湖边、山里 |

### Step 4：停车规划

| 场景 | 停车策略 |
|------|---------|
| 住宿 | 优先选有免费停车的酒店 |
| 活动场馆 | 车停酒店，地铁/步行去场馆 |
| 游玩日 | 按片区规划停车点，减少挪车 |
| 景点停车 | 提前查高德 API 周边停车场 |

### Step 5：返程时间倒推

```
到家时间上限 - 驾驶时间 - 服务区休息(15min) = 最晚出发时间
```

**示例**：24:00 到家 - 4.5h 驾驶 - 0.25h 休息 = 19:15 最晚出发

## ⚠️ 自驾 + 活动常见坑

| 坑 | 预防 |
|----|------|
| 活动散场停车堵 | 车停酒店，地铁/步行去场馆 |
| 散场太晚没地铁 | 提前查末班车时间 |
| 高速夜间疲劳 | 中途停服务区休息 15 分钟 |
| 活动当天没时间玩 | 当天只安排活动，不塞景点 |
| 住宿离场馆太远 | 住宿选场馆 3km 范围内 |
| 周末景区停车难 | 提前查停车场+备选方案 |
| 雨天高速危险 | 查天气预报，带伞，降速 |
