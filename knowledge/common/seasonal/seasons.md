# Seasonal Travel Guide — 季节与目的地

> 开源版本 — 通用季节建议

---

## 🌸 春季（3-5月）

### 最佳目的地

| 目的地 | 特色 | 最佳时段 |
|--------|------|---------|
| 西藏林芝 | 桃花节 | 3月下-4月中 |
| 无锡鼋头渚 | 樱花 | 3月中-4月初 |
| 婺源 | 油菜花 | 3月 |
| 武汉 | 樱花 | 3月中-4月初 |
| 日本 | 樱花季 | 3月下-4月中 |
| 荷兰 | 郁金香 | 4月-5月中 |

### 注意事项

- 🌸 花粉过敏者戴口罩
- 🌧️ 江南梅雨季，带雨具
- 👗 洋葱式穿衣（温差大）

---

## ☀️ 夏季（6-8月）

### 推荐目的地

| 目的地 | 特色 | 最佳时段 |
|--------|------|---------|
| 青海湖 | 油菜花+湖景 | 7-8月 |
| 呼伦贝尔 | 草原 | 6-8月 |
| 北海道 | 花田+避暑 | 7-8月 |
| 贵州 | 避暑（爽爽的贵阳） | 6-8月 |
| 神农架 | 避暑+原始森林 | 6-8月 |
| 川西 | 高山草甸 | 7-8月 |

### 注意事项

- ☀️ 防晒（SPF50+）
- 🦟 防蚊（尤其湿地/草丛）
- 🌊 水上活动注意安全
- ⛈️ 雷阵雨频发，查天气预报

---

## 🍂 秋季（9-11月）

### 最佳旅行季（黄金季节）

| 目的地 | 特色 | 最佳时段 |
|--------|------|---------|
| 喀纳斯 | 秋色 | 9月下-10月初 |
| 北京 | 香山红叶 | 10月下-11月上 |
| 九寨沟 | 彩林+水色 | 10月中-11月上 |
| 稻城亚丁 | 秋色 | 10月中-11月初 |
| 加拿大 | 枫叶 | 9月-10月 |
| 日本 | 红叶 | 11月 |

### 注意事项

- 🧥 昼夜温差大，带厚外套
- 📸 摄影黄金季节，带够电池（冷耗电快）
- 🍂 高原地区可能下雪，注意路况

---

## ❄️ 冬季（12-2月）

### 两种玩法

| 类型 | 目的地方向 | 推荐 |
|------|-----------|------|
| 避寒 | 海南/云南/东南亚 | 三亚、西双版纳、泰国 |
| 看雪 | 东北/日本/北欧 | 哈尔滨、北海道、芬兰 |

### 注意事项

- 🧥 保暖分层穿衣（羽绒服+抓绒+保暖内衣）
- ⚠️ 冰雪路面防滑鞋
- 🏠 北方室内干燥，带保湿
- ✈️ 关注暴雪/冻雨对航班影响

---

## 🎋 节日与假期

| 日期 | 节日 | 旅行建议 |
|------|------|---------|
| 春节（1-2月） | 家庭团聚 | 返乡高峰，错峰出行 |
| 清明（4月） | 祭祖+踏青 | 江南踏青好时节 |
| 五一（5月） | 小长假 | 人多价高，提前订 |
| 端午（5-6月） | 短假 | 周边游合适 |
| 中秋（9月） | 团圆 | 短期周边游 |
| 国庆（10月） | 黄金周 | 挤！提前订！暑假或错峰更好 |

## 🌧️ 特殊天气

| 天气 | 影响 | 应对 |
|------|------|------|
| 梅雨 | 长江流域 6-7月 | 雨具、备选室内 |
| 台风 | 华南/华东 7-9月 | 关注预警、避开山区 |
| 沙尘暴 | 北方 3-5月 | 口罩、护眼 |
| 雾霾 | 北方冬季 | 口罩、减少户外 |
| 高温 | 7-8月 | 避暑、防暑药、多喝水 |
| 寒潮 | 冬季 | 保暖、防滑 |
