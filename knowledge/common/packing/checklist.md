# Packing Lists — 行李清单

> 开源版本 — 通用行李清单

---

## 🎒 通用清单

All travelers should pack:

### 证件 & 财务

- [ ] 身份证 / 护照
- [ ] 驾照（如需自驾）
- [ ] 学生证（景点优惠）
- [ ] 少量现金 + 银行卡

### 电子产品

- [ ] 手机 + 充电线
- [ ] 充电宝
- [ ] 耳机
- [ ] 转换插头（出境）

### 洗漱 & 个护

- [ ] 牙刷牙膏（酒店未必好用）
- [ ] 洗面奶/护肤品分装
- [ ] 防晒霜（SPF50+）
- [ ] 纸巾/湿巾

### 衣物

- [ ] 内衣裤（N+1 套）
- [ ] 袜子（N+1 双）
- [ ] 舒适走路鞋
- [ ] 拖鞋（酒店/火车/沙滩）
- [ ] 外套（防风/保暖）
- [ ] 睡衣
- [ ] 泳装（如需）

### 药品

- [ ] 感冒药
- [ ] 肠胃药
- [ ] 创可贴
- [ ] 防蚊喷雾（夏季/热带）
- [ ] 晕车/晕船药

---

## 🌡️ 季节性追加

### 夏季追加

- [ ] 防晒霜（SPF50+）
- [ ] 防晒衣/遮阳帽
- [ ] 墨镜
- [ ] 风扇（小折扇）
- [ ] 防蚊喷雾
- [ ] 藿香正气水（中暑）

### 冬季追加

- [ ] 羽绒服
- [ ] 保暖内衣
- [ ] 手套/围巾/帽子
- [ ] 暖宝宝
- [ ] 保湿面霜（北方干燥）
- [ ] 防滑鞋/冰爪

### 雨季追加

- [ ] 雨伞/雨衣
- [ ] 防水袋（电子设备）
- [ ] 速干衣物
- [ ] 备用鞋

---

## 🏔️ 特殊目的地追加

### 高原（西藏/青海/川西）

- [ ] 红景天（提前 3-7 天服用）
- [ ] 葡萄糖口服液
- [ ] 保温杯
- [ ] 高倍防晒（紫外线强）
- [ ] 润唇膏（极干燥）
- [ ] 遮阳帽

### 海边

- [ ] 泳衣/沙滩裤
- [ ] 沙滩巾
- [ ] 防水手机袋
- [ ] 水母衣（防晒+防蛰）
- [ ] 珊瑚友好型防晒霜

### 东南亚/热带

- [ ] DEET 驱蚊液
- [ ] 肠胃药（食物卫生）
- [ ] 免洗洗手液
- [ ] 长袖薄衣（防晒+防蚊）
- [ ] 雨具（雨林气候多变）

---

## ✈️ 特殊场合追加

### 商务

- [ ] 正装
- [ ] 名片

### 摄影

- [ ] 相机 + 备用电池
- [ ] 三脚架/自拍杆
- [ ] 存储卡（至少 2 张）
- [ ] 镜头纸/气吹

### 亲子

- [ ] 儿童常用药
- [ ] 备用衣物（小孩容易弄脏）
- [ ] 零食
- [ ] 玩具/绘本（路上安抚）

---

## ⚠️ 安检禁带

| 禁带 | 限制 |
|------|------|
| 液体容器 | 单瓶 ≤100ml，总量 ≤1L，装透明袋 |
| 充电宝 | ≤20000mAh ≤100Wh，必须随身携带 |
| 打火机/火柴 | 禁止携带和托运 |
| 刀具 | 禁止携带，托运按规定 |
| 烟花/爆竹 | 禁止 |
