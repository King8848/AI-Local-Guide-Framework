## 🌡️ 旅行前准备

### 体检建议

| 人群 | 建议 |
|------|------|
| 慢性病患者 | 出发前复查，确认状态稳定 |

| 类别 | 常用药 |

| 过敏 | 氯雷他定 |
| 外伤 | 创可贴、碘伏棉签 |
| 防蚊 | DEET 驱蚊液 |

## 🏔️ 高原反应

### 高风险地区

| 地区 | 海拔 | 风险等级 |
|------|------|---------|
| 拉萨 | 3650m | 高 |
| 丽江 | 2400m | 中 |
| 大理 | 2000m | 低 |
| 香格里拉 | 3300m | 高 |
| 玉龙雪山 | 4680m | 极高 |

### 预防措施

1. 上升不要过急，每天上升 <500m
2. 多喝水，忌酒，清淡饮食
3. 提前服用红景天（出发前 3-7 天）
4. 到达当天不要洗澡，不要剧烈运动

### 症状分级

| 程度 | 症状 | 处理 |
|------|------|------|
| 轻度 | 头痛、乏力、失眠 | 休息、多喝水、吸氧 |
| 中度 | 呕吐、胸闷严重 | 立即吸氧、下撤 |
| 重度 | 意识模糊、口唇发紫 | 紧急送医、立即下撤 |

## 👩 特殊人群

### 孕妇

| 孕期 | 建议 |
|------|------|
| 0-3月 | 不建议远行（流产风险高） |
| 4-7月 | 最稳定期，可适度旅行 |
| 8月+ | 不建议远行（早产风险） |

### 儿童

| 关注 | 建议 |
|------|------|
| 饮食 | 自带食物，避免生冷 |
| 睡眠 | 保持规律作息 |
| 安全 | 高铁/飞机选靠窗位（不乱跑） |

### 老年人

| 关注 | 建议 |
|------|------|
| 慢病药 | 带足常用药 + 处方 |
| 节奏 | 每天活动量减半 |
| 保险 | 购买旅行意外险 |
