## 🎒 行李清单

### 证件类

| 必需 | 建议 |
|------|------|
| 身份证/护照 | 学生证（景点优惠） |
| 驾照（自驾游） | 国际驾照认证件 |

### 电子产品

| 必需 | 建议 |
|------|------|
| 手机 + 充电线 | 充电宝（20000mAh 以内可带上飞机） |
| 耳机 | 自拍杆/三脚架 |

### 药品

| 通用 | 视情况 |
|------|--------|
| 感冒药 | 高原反应药（高海拔） |
| 肠胃药 | 晕车药 |
| 创可贴 | 防蚊喷雾 |

### 衣物

根据目的地气候准备，通用Tips：
- 舒适走路鞋（最重要！）
- 一件防风外套（几乎任何场景都用得上）
- 多备几双袜子

## ✈️ 机场/车站

### 国内航班

| 项目 | 建议 |
|------|------|
| 提前到达 | 航班起飞前 1.5-2 小时 |
| 值机 | 建议提前在线值机选座 |
| 安检 | 充电宝、液体提前拿出来 |

### 高铁

| 项目 | 建议 |
|------|------|
| 提前到达 | 30 分钟足够 |
| 选座 | A/F 靠窗，C/D 过道 |
| 进食 | 高铁站吃饭偏贵，提前买好 |

## 🏨 住宿选择

### 选址原则

1. **交通便利** — 地铁/公交通达
2. **安全第一** — 选择评价好的区域
3. **性价比高** — 不一定非住景区旁
4. **安静** — 避开酒吧街/夜市旁（除非你想体验）

### 类型对比

| 类型 | 适合 | 优点 | 缺点 |
|------|------|------|------|
| 酒店 | 追求品质 | 设施全 | 价格高 |
| 青旅 | 独行/省钱 | 社交氛围 | 隐私差 |
| 民宿 | 家庭/深度 | 居家体验 | 标准化低 |
| 胶囊 | 过夜/省钱 | 便宜 | 空间小 |

## 💳 支付与安全

### 支付工具

| 场景 | 推荐 |
|------|------|
| 国内 | 微信/支付宝/云闪付 |
| 国际 | Visa/Mastercard + 少量现金 |
| 网上预订 | 支付宝/微信国际/信用卡 |

### 安全提醒

- ⚠️ 不要在 WiFi 下操作支付
- ⚠️ 公共充电桩慎用（可被植入恶意软件）
- ⚠️ 备份护照/证件到云端
