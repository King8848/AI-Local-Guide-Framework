## 🍖 地区特色美食 · 琼海

> 🗺️ 概览：博鳌名城与温泉之乡，温泉鹅与杂粮的琼海味道
> 💡 本地人口味：清淡养生，杂粮糯米，温泉鹅是招牌
> 📖 琼海融合了博鳌的国际化与本地的杂粮养生文化，嘉积鸭、温泉鹅、杂粮构成了独特的万泉河饮食风味

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **博鳌亚洲论坛永久会址+玉带滩** → 上午游览，下午看三河入海口奇观
- [ ] **潭门渔港海鲜** → 傍晚去渔港买海鲜，大排档加工
- [ ] **官塘温泉泡汤** → 晚上放松，含氡硅氟医疗热矿泉

### 【推荐】选 3-5 个

- [ ] **嘉积鸭** → 午餐去昌隆饭店吃正宗白切/酱板烤两吃
- [ ] **白石岭登高** → 早晨去，俯瞰博鳌全景
- [ ] **海的故事** → 傍晚看日落，喝咖啡
- [ ] **万泉河漂流** → 下午体验海南第三大河
- [ ] **南海博物馆** → 了解南海渔文化/《更路簿》

### 【可选】有时间加

- [ ] 博鳌禅寺（半天）
- [ ] 潭门渔港出海体验（半天）
- [ ] 嘉积老街骑楼（2-3小时）
- [ ] 万泉河入海口湿地（2-3小时）

### 【交通建议】

- 琼海站/博鳌站高铁直达，从海口约50分钟/三亚约1.5小时
- 博鳌站到博鳌亚洲论坛会址约15分钟车程
- 琼海市内景点间距离较远，建议网约车/自驾
- 博鳌镇内可步行/骑行游览

### 【住宿建议】

- **首选**：博鳌东屿岛高端度假酒店（近论坛会址）
- **次选**：官塘温泉度假区（泡汤度假）
- **经济型**：嘉积市区（交通便利，生活气息浓）

## 💡 避坑指南

### ✅ 建议
1. 博鳌亚洲论坛永久会址建议请讲解，了解亚洲政治经济格局
2. 潭门海鲜建议下午4-5点去渔港，渔民刚回来最新鲜
3. 嘉积鸭推荐白切/酱板烤两吃，品尝原味
4. 官塘温泉建议冬季去，体验更佳
5. 玉带滩联票包含在博鳌会址门票内，单独买不划算

### ❌ 避雷
1. **出租车司机推荐的海鲜店**：有回扣
2. **景区"特产店"**：价格虚高，去嘉积中心市场
3. **低价一日游团**：强制消费
4. **非正规海鲜加工店**：加工前确认价格
