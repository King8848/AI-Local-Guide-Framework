## 🍖 地区特色美食 · 桂林

> 🗺️ 概览："不吃米粉，等于没来过桂林。"桂林米粉是这座城市的美食图腾，而啤酒鱼、荔浦芋扣肉则是漓江两岸的经典风味。
> 💡 本地人口味特点：— 酸辣鲜香、卤水是灵魂；吃米粉讲究"先干拌后喝汤"；爱喝油茶，打油茶是待客之道
> 📖 饮食文化简述：桂林米粉有着3000多年历史，是秦代灵渠工匠用米粉替代面条的智慧创造。当地人一日三餐都可以吃米粉。

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **漓江竹筏（杨堤-兴坪段）** → 清晨6-7点出发，九马画山/黄布倒影/20元人民币背景
- [ ] **桂林米粉** → 早上去石记/又益轩，感受本地人早餐仪式
- [ ] **阳朔西街** → 晚上逛街+酒吧+小吃

### 【推荐】选 3-5 个

- [ ] **两江四湖夜游** → 晚7点后，灯影桂林
- [ ] **象鼻山** → 清晨或傍晚，避开旅行团
- [ ] **龙脊梯田** → 秋天去，住一晚看日出
- [ ] **椿记烧鹅** → 晚餐，桂林烧鹅代表
- [ ] **遇龙河** → 下午竹筏，比漓江更静谧

### 【可选】有时间加

- [ ] 靖江王城（半天）
- [ ] 桂林博物馆（半天）
- [ ] 银子岩（2-3小时）
- [ ] 东西巷闲逛（1-2小时）
- [ ] 猫儿山（一天，自驾）

### 【交通建议】

- 桂林到阳朔：竹筏/大巴约1.5小时
- 阳朔到龙脊：大巴约2小时
- 市区公交2元，去阳朔在汽车南站坐车
- 去龙脊建议报团或自驾

### 【住宿建议】

- **首选**：秀峰区象鼻山/两江四湖，核心景区
- **次选**：阳朔西街附近，深度游可住1-2晚
- **经济型**：七星区，性价比高

## 💡 避坑指南

### ✅ 建议
1. 漓江竹筏选杨堤-兴坪精华段（约4小时），约200元/人
2. 阳朔西街晚上去，白天游客多+晒
3. 米粉去本地人扎堆的店，不要看装修
4. 荷花鱼/啤酒鱼注意 ⚠️ **过敏**，点菜时提前告知
5. 龙脊梯田住宿提前预订，旺季满房
6. 租电动车骑行十里画廊，约30元/天

### ❌ 避雷
1. **景区门口"老乡"**：带去买特产可能有回扣
2. **低价一日游**：强制消费，正常一日游200+
3. **阳朔主街特产店**：价格虚高，去超市买
4. **出租车不打表**：坚持打表或网约车
5. **两江四湖白天游**：夜景才值得花钱，白天无聊
