## 🏙️ 城市灵魂

**兰州：一碗牛肉面唤醒的黄河之城。**
黄河穿城而过，兰州是西北最会吃的城市。清晨六点，满城都是牛肉面的香味。一碗面、一本书、一座桥——兰州的精髓，藏在大街小巷的烟火气里。

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **牛肉面过早** → 早7点前，马子禄或磨沟沿，排队值得
- [ ] **甘肃省博物馆** → 看马踏飞燕，丝绸之路文明展
- [ ] **白塔山+中山桥** → 傍晚登山+看铁桥夜景

### 【推荐】选 3-5 个

- [ ] **正宁路夜市** → 晚饭后逛吃，牛奶鸡蛋醪糟必试
- [ ] **黄河母亲雕塑** → 顺路打卡，黄河打卡地标
- [ ] **黄河风情线骑行/散步** → 沿黄河骑行5公里
- [ ] **读者杂志社打卡** → 文化地标
- [ ] **泛舟羊皮筏子** → 黄河体验

### 【可选】有时间加

- [ ] 皋兰山登顶（半天）
- [ ] 兰州博物馆（半天）
- [ ] 黄河游船（1小时）
- [ ] 安宁桃花会（3-4月）

### 【交通建议]

- 黄河风情线适合步行+骑行
- 地铁1号线贯穿东西
- 白塔山/中山桥步行可达
- 羊皮筏子从中山桥附近上船

### 【住宿建议]

- **首选**：城关区中山桥/正宁路，景点集中+夜市近
- **次选**：七里河区滨河路，黄河沿线安静
- **经济型**：安宁区/西固区，大学城周边性价比高

## 💡 避坑指南

### ✅ 建议

1. 牛肉面早上去，6-10点最佳，下午面会坨
2. ⚠️ 小龙虾过敏警告：正宁路夜市偶有小龙虾摊位，过敏者请避开
3. 手抓羊肉去正宁路或老字号，别去景区门口
4. 正宁路夜市最推荐：牛奶鸡蛋醪糟、羊肉串
5. 甘肃省博物馆提前公众号预约，马踏飞燕在二楼

### ❌ 避雷

1. 牛肉面店别去装修太好的，老字号味道正宗
2. 景区手抓羊肉贵且不正宗
3. 出租车司机推荐的手抓店可能有回扣
4. 夏天兰州暴晒注意防晒
5. 黄河边风大带件外套
