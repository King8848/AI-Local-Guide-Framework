## 🍖 地区特色美食 · 伊犁

> 🗺️ 概览：伊犁是新疆少有的"鱼米之乡"——天山雪水灌溉的丰茂草原孕育了独特的牧区美食，哈萨克手抓、六星街俄式糕点、锡伯族熏马肠在此交融，空气中弥漫着蜂蜜与苜蓿的清香。
> 💡 本地人口味特点：偏爱牛羊肉与奶制品（马奶/酸奶），口味偏咸鲜，喜食烟熏风味（马肠/乳酪），早餐奶茶配奶油/酥油
> 📖 饮食文化简述：伊犁饮食是典型的"草原丝路"产物——哈萨克牧民的毡房饮食（手抓肉、马奶酒）、锡伯族的东北风味（面茶、发面饼）、塔塔尔/俄族的欧式糕点（巴哈拉）、维吾尔传统（拉条子/烤肉）在此多元共生。六星街一条街上，你能同时遇见俄式列巴房、塔塔尔糕点和维吾尔馕坑。

### 📝 美食文化笔记

- **餐桌礼仪**：哈萨克族待客以"巴塔"（祝祷词）开场，主人念祝词后先切羊头肉敬客人；喝奶茶时主人续茶不可拒绝，空碗表示"再来一碗"；马奶酒需双手接碗，先敬天地再饮
- **节日食俗**：纳吾鲁孜节（3/21）家家煮"纳吾鲁孜粥"（七种食材），象征新年丰收；古尔邦节宰牲后，羊头敬长辈、羊腿送邻居；肉孜节开斋以椰枣/奶茶起始
- **生活讲究**：牧区"无奶不成餐"——奶茶是日常刚需，奶皮子待客是标配；牲畜"夏壮秋肥冬瘦春死"决定饮食节奏——夏天鲜食、秋天腌制、冬天存干；六星街的塔塔尔族仍保留俄式下午茶传统，一人一壶茶配糕点聊一小时

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **喀赞其民俗旅游区** → 上午去坐马车逛老城
- [ ] **赛里木湖**（自驾）→ 路过霍城时顺便解忧公主薰衣草园
- [ ] **那拉提一日游/G217自驾** → 如果住在伊宁市，需包车或一日团

### 【推荐】选 3-5 个

- [ ] **六星街** → 傍晚/晚上
- [ ] **果子沟大桥**（去赛里木湖路上必经）→ 傍晚最佳
- [ ] **特克斯八卦城+离街** → 住一晚
- [ ] **霍尔果斯口岸+中哈合作区** → 半天
- [ ] **伊宁→伊宁河大桥看黄昏**

### 【可选】有时间加

- [ ] **巴音布鲁克**（从伊宁5h，需2天）
- [ ] **夏塔古道徒步**（从伊宁4h+2天徒步）
- [ ] **昭苏天马文化园**（距伊宁3h）
- [ ] **库尔德宁**（草原+雪山）

### 【交通建议】

- **乌鲁木齐 → 伊宁**：火车7h，飞机1h（旺季机票贵）
- **伊宁 → 那拉提**：4h山路，包车约800-1000元/天
- **伊宁 → 赛里木湖**：2h，必走果子沟大桥
- **自驾最佳**：伊犁景点分散，公共交通弱

### 【住宿建议】

- **首选**：伊宁市斯大林路/解放路 → 市区中心
- **那拉提**：镇上民宿，提前预订
- **特克斯**：县城酒店，离街步行

## 💡 避坑指南

### ✅ 建议

1. **6月中-7月初去**，薰衣草+草原花期
2. **自驾最方便**，景点太散，跟团体验差
3. **那拉提住景区贵**，住那拉提镇更实惠
4. **柏鸠克马车先谈价**，被宰是常态
5. **景区内骑马谈好价**，不然会收费翻倍
6. **赛里木湖建议逆时针开**，减少回头路

### ❌ 避雷

1. **赛里木湖区间车排队**——自驾更自由
2. **那拉提不提前买票**——旺季门票紧张
3. **伊宁机场离市区远**——打车100元+，大巴30元
4. **特克斯坐"热气球"**——价格虚高，性价比低
