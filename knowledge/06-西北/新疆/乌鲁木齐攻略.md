## 🏙️ 城市灵魂

**乌鲁木齐：丝路上的西域明珠，多民族融合的北国春城。**
清晨一碗奶茶配烤包子，中午一盘拉条子配手抓饭，夜晚大巴扎灯火通明。这里是通往中亚的门户，也是新疆美食的大本营。维吾尔族的热情好客、哈萨克族的豪迈洒脱、回族人的精细讲究，在这座城市中碰撞出独特的生活美学。

### 📝 美食文化笔记
- **餐桌礼仪**：清真餐厅不饮酒不带猪肉；馕要掰成小块吃，不可整块咬
- **节日食俗**：肉孜节家家户户烤全羊，古尔邦节宰牲分肉给亲友
- **生活讲究**："早茶午面晚肉"——乌鲁木齐人的一天围绕这三种食物展开；新疆与北京时差约2小时，调整用餐时间

### 【必做】选 2-3 个

- [ ] **烤全羊/手抓饭** → 晚餐，新疆灵魂美食

### 【推荐】选 3-5 个

- [ ] **红山公园** → 傍晚散步，俯瞰城市
- [ ] **天山大峡谷** → 一天行程，天山风光
- [ ] **南山牧场** → 夏天去草原骑马
- [ ] **友好路夜市** → 晚上烧烤街
- [ ] **阿布拉的馕** → 早餐必去

### 【可选】有时间加

- [ ] 水磨沟公园（半天）
- [ ] 新疆地质博物馆（2小时）
- [ ] 二道桥老城闲逛（1-2小时）

### 【交通建议】

- 市区景点地铁1号线+公交/BRT覆盖

- 打车起步价10元，打表

### 【住宿建议】

- **首选**：天山区大巴扎/南门，核心景区+美食集中
- **次选**：沙依巴克区友好/红山，现代舒适
- **经济型**：新市区铁路局，性价比高

## 💡 避坑指南

### ✅ 建议

1. 新疆与北京时差约2小时，调整用餐时间
2. 大巴扎晚上去，热闹+小吃多
3. 烤全羊提前预订，需现烤
4. 新疆干燥，多喝水+保湿
5. 清真餐厅尊重民族习俗，不带酒/猪肉

### ❌ 避雷

1. 景区门口"老乡"推荐的羊肉店——可能差+贵
2. 大巴扎内购买贵重玉器——不懂行别买
3. 出租车不打表——坚持打表或网约车
4. 新疆紫外线极强——SPF50+必备
