## 🏙️ 城市灵魂

**"西藏的江南，高原的桃花源。**
海拔仅2900米，含氧量西藏最高，林芝是高原新手最佳入门地。3月底-4月初，漫山遍野的野生桃花与南迦巴瓦雪峰交相辉映——这里是每个"藏旅行者"的第一站。

## 🍖 地区特色美食 · 林芝

> 🗺️ 概览：工布藏区的山野至味——藏香猪的酥香、石锅鸡的鲜嫩、蕨麻猪肉的醇厚与百种青稞的芬芳，在尼洋河谷的晨雾中交织成林芝独有的高原食单。
> 💡 本地人口味特点：咸鲜为本，喜重油厚味，以耐高寒；吃藏香猪肉必配青稞酒
> 📖 饮食文化简述：林芝地处藏东南，印度洋暖湿气流带来丰饶物产，形成与拉萨、日喀则截然不同的"工布饮食体系"。鲁朗石锅鸡以皂石为器、松茸为辅，藏香猪奔跑于原始森林间、肉质紧实如笋，蕨麻猪则以高原人参果为食、肥而不腻。藏族、门巴族、珞巴族杂食共处，造就了林芝野、鲜、淳、厚的独特风味。

### 📝 美食文化笔记

- **餐桌礼仪**：入藏家先喝酥油茶、吃糌粑表谢意；刀刃不可朝人；主人添茶不可一口喝完，留底表示还想添
- **节日食俗**：工布新年（藏历十月）必吃"恰果贰"（包石头的羊肉馅饺子），吃到石头者寓意来年好运
- **生活讲究**：藏族人席地而坐，男左女右分坐；吃肉先敬老人和客人；青稞酒三口一杯是铁律，不可打破

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **南迦巴瓦+雅鲁藏布大峡谷** → 包车一日往返派镇
- [ ] **巴松措** → 半日/一日，住景区附近最好
- [ ] **鲁朗花海+林海** → 路过318必停，石锅鸡午饭

### 【推荐】选 3-5 个

- [ ] **色彩拉山口** → 南迦巴瓦远眺
- [ ] **尼洋河风光带** → 晨昏漫步
- [ ] **嘎拉桃花沟（仅3-4月）** → 桃花节
- [ ] **波密/米堆冰川** → 波密方向一日
- [ ] **林芝市博物馆** → 了解工布文化

### 【可选】有时间加

- [ ] **墨脱**（需边防证，至少2天）
- [ ] **察隅方向**（需边防证）
- [ ] **拉多藏湖**（偏远）

### 【交通建议】

- **拉萨 → 林芝**：5h高速，自驾/大巴
- **林芝 → 波密**：240km，5h山路
- **林芝 → 派镇（雅江景区）**：90km，2h
- **林芝 → 鲁朗**：80km，1.5h
- **自驾最佳**：景点分散，跟团受拘束

### 【住宿建议】

- **首选**：八一镇行政中心 → 市区中心
- **看南迦巴瓦**：索松村/派镇民宿
- **花季/摄影**：鲁朗花海附近民宿

## 💡 避坑指南

### ✅ 建议

1. **先去林芝后去拉萨**：林芝海拔低适应后更好适应高反
2. **3-4月桃花节住宿**：提前2个月以上预订
3. **包车看营运证**：正规营运车有黄色顶灯
4. **巴松措住景区**：看星空+晨雾
5. **南迦巴瓦看到看命**：多住一晚多一次机会

### ❌ 避雷

1. **墨脱封路季节**：10月-次年6月封路
2. **景区门口买药材**—游客价高10倍
3. **不要随意拍摄藏民**—拍前先问
4. **雅鲁藏布区间车排队**——自驾或包车更方便
