## 🏙️ 城市灵魂

**济南：把泉水的温润和鲁菜的豪迈揉在一座城市里。**
清晨趵突泉边打泉水泡茶，傍晚大明湖畔看超然楼亮灯，深夜芙蓉街小吃摊前排队。这座"四面荷花三面柳，一城山色半城湖"的泉城，用最慢节奏迎接每一个匆忙的旅人。

## 🍖 地区特色美食 · 济南

> 🗺️ 概览：济南是鲁菜的发源地之一，把子肉、油旋、甜沫是济南人的"早餐三件套"；泉水泡茶是济南人的生活方式
> 💡 本地人口味特点：咸鲜为主，偏油偏香，讲究火候与镬气
> 📖 饮食文化简述：济南自古为齐鲁大地政治文化中心，鲁菜是中国四大菜系之首，而济南菜是鲁菜的核心支柱。济南南依泰山、北临黄河，七十二名泉赋予这座城市独特的饮食灵魂——用泉水泡的茶格外甘甜，用泉水做的菜格外鲜嫩。济南人讲究"大口吃肉、大碗喝酒"，豪爽的山东性格在饮食中体现得淋漓尽致。

### 📝 美食文化笔记
- **餐桌礼仪**：山东人喝酒讲究"主陪、副陪"，敬酒规矩多，客人不醉主人没招待好
- **节日食俗**：春节包饺子、炸酥菜；中秋吃月饼；冬至吃饺子
- **生活讲究**：济南人"不喝茶、只喝泉水茶"——趵突泉边打泉水泡茶是济南人的日常仪式

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **趵突泉+打泉水** → 早上6:30-9:00，天下第一泉+自带杯子接泉水
- [ ] **大明湖夜游** → 晚上19:00-21:00，超然楼亮灯
- [ ] **芙蓉街** → 晚上，济南最热闹小吃街

### 【推荐】选 3-5 个

- [ ] **千佛山** → 日出或日落，俯瞰济南城
- [ ] **黑虎泉打泉水** → 早上去，看济南市民打泉水盛况
- [ ] **鲁菜正餐（城南往事/聚丰德）** → 午餐/晚餐，糖醋鲤鱼+九转大肠+奶汤蒲菜
- [ ] **把子肉+甜沫** → 早餐/午餐，济南快餐代表
- [ ] **曲水亭街+百花洲** → 下午休闲，小桥流水+泉水人家
- [ ] **山东博物馆** → 半天，了解齐鲁文化

### 【可选】有时间加

- [ ] 九如山瀑布群（一天，夏天/秋天）
- [ ] 红叶谷（半天到一天，10月中下旬）
- 济南战役纪念馆（2小时）
- 灵岩寺（半天，在长清区）
- 章丘百脉泉（一天，明水街道）

### 【交通建议】

- 地铁1/2/3号线覆盖主城区，泉城路步行即可
- 老城区景点集中，步行+骑行最佳
- 千佛山建议打车或公交前往
- 九如山/红叶谷需自驾或旅游专线

### 【住宿建议】

- **首选**：历下区趵突泉/大明湖附近，泉水+老城+小吃集中
- **次选**：市中区英雄山，千佛山附近
- **经济型**：槐荫区济南西站附近，交通便利

## 💡 避坑指南

### ✅ 建议

1. 趵突泉早上6:30-8:00人最少，泉水喷涌最旺
2. 九如山秋天去（10月中下旬），红叶最美
3. 芙蓉街晚上去，灯火通明最热闹，但别指望性价比
4. 鲁菜偏咸偏油，点菜时备注"少盐少油"
5. 黑虎泉打泉水的人多但值得体验，早上去看济南市民生活
6. 济南出租车便宜，起步9元，打车方便

### ❌ 避雷

1. 芙蓉街小吃比外面贵，但可以接受
2. 出租车司机推荐的餐厅可能有回扣，大众点评看评分
3. 趵突泉门口花瓶里的矿泉水不要买，趵突泉公园内可直接接泉水
4. 黑虎泉到趵突泉有一段路较杂乱，注意安全
5. 九如山景区内物价高，自带食物和水
