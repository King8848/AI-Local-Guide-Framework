## 🍖 地区特色美食 · 南昌

> 🗺️ 概览：南昌是一座被米粉统治的城市，拌粉配瓦罐汤是最质朴也最狂热的味觉信仰
> 💡 本地人口味特点：嗜辣如命，"微辣"也足以击穿外地人的味蕾防线
> 📖 饮食文化简述：南昌地处赣江与鄱阳湖交汇处，自古稻作发达，米粉文化源远流长。南昌人不吃早餐叫"过早"，而"过早"的正统仪式就是一碗拌粉加一罐瓦罐汤。辣与鲜是赣菜灵魂，本地人奉行"无辣不欢"，辣椒往往比主菜还多。

### 📝 美食文化笔记
- **餐桌礼仪**：南昌人吃饭叫"恰饭"，劝菜用"切切切"（吃吃吃），干杯叫"啵一个"
- **节日食俗**：春节必吃藜蒿炒腊肉（谐音"好事"），端午要饮雄黄酒
- **生活讲究**："早餐是宗教，夜宵是信仰"，南昌人的两条美食生命线

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **熊记拌粉过早** → 早7点前，本地人早餐仪式
- [ ] **滕王阁日落** → 下午4-5点，看完日落等亮楼
- [ ] **蛤蟆街夜宵** → 晚10点后，本地人深夜食堂

### 【推荐】选 3-5 个

- [ ] **秋水广场喷泉** → 晚7:30/8:30，提前占位
- [ ] **699文创园** → 下午，周六有市集
- [ ] **系马桩喝茶** → 下午杀时间，看车来车往
- [ ] **绳金塔夜市** → 傍晚，边走边吃
- [ ] **民间小厨赣菜** → 午餐/晚餐，本地人聚餐地

### 【可选】有时间加

- [ ] 瑶湖骑行（半天）
- [ ] 江西省博物馆（半天）
- [ ] 梅岭狮子峰（一天）
- [ ] 万寿桥庙会（节假日）

### 【交通建议】

- 老城区景点步行可达，系马桩到蛤蟆街打车10分钟
- 去瑶湖地铁1号线，去秋水广场地铁1号线
- 梅岭建议自驾或公交540路

### 【住宿建议】

- **首选**：老城区叠山路/中山路，小吃集中、交通方便
- **次选**：红谷滩秋水广场附近，江景+现代
- **经济型**：青山湖区上海路，高校周边

## 💡 避坑指南

### ✅ 建议
1. 早餐店选排队的，南昌人嘴刁，不好吃早倒闭了
2. 辣度要备注——南昌的"微辣"≈外地中辣
3. 夜宵去苍蝇馆子，装修越破可能越好吃
4. 夏天吃小龙虾 🦞**过敏警告**：南昌满街都是，本人过敏请勿推荐
5. 拌粉+瓦罐汤是标配，一个干的一个稀的一比一搭配

### ❌ 避雷
1. 景区门口土特产店价格虚高50-100%
2. 出租司机推荐的餐厅可能有回扣
3. 网红店排队超过1小时——南昌好吃的没必要排这么久
4. 6-7月梅雨季暴雨说来就来，随身带伞
