## 🏙️ 城市灵魂

**沈阳：把烧烤和洗浴刻进DNA的城市。**
清晨一碗大果子配豆浆，深夜一堆烤串配老雪。这座东北最大的城市，粗犷的外表下藏着一整部清前史，还有让本地人骄傲的洗浴江湖。

## 🍖 地区特色美食 · 沈阳

> 🗺️ 概览：沈阳是东北美食的集大成者——老边饺子是百年传奇，西塔韩餐是异域风情，烧烤+老雪是深夜的灵魂。
> 💡 本地人口味特点：— 咸鲜重口、量大实惠；锅包肉要趁热吃；烧烤配老雪是标配
> 📖 饮食文化简述：沈阳饮食深受满族和朝鲜族文化影响，既有满族的炖菜面食传统，又有西塔韩餐的异域风情，加上东北烧烤和洗浴文化的深度融合。

### 📝 文化笔记

- **餐桌礼仪**：— 沈阳人"大口喝酒，大块吃肉"，豪爽是待客之道；烧烤摊前自己动手的"自助"是传统
- **节日食俗**：— 除夕吃饺子/锅包肉/杀猪菜；冬至吃饺子；正月十五吃元宵
- **生活讲究**：— 沈阳人"没有什么是一顿烧烤解决的，如果有，就两顿"；洗浴中心+烧烤是周末标配

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **沈阳故宫** → 早8:30入园，中国仅存的两大皇宫建筑群之一
- [ ] **西塔韩餐+烧烤** → 晚上去，沈阳灵魂所在
- [ ] **洗浴文化体验** → 晚上泡澡+搓澡，沈阳特色

### 【推荐】选 3-5 个

- [ ] **张氏帅府** → 上午/下午，紧邻故宫
- [ ] **辽宁省博物馆** → 周末去，需预约，留半天
- [ ] **老边饺子** → 午餐，百年老字号
- [ ] **浑河骑行** → 日落时
- [ ] **中街夜生活** → 晚饭后逛街+夜市

### 【可选】有时间加

- [ ] 1905文创园（半天）
- [ ] 九一八博物馆（2小时）
- [ ] 北陵公园（半天）
- [ ] 刘老根大舞台二人转（晚上）

### 【交通建议】

- 沈阳地铁1/2/4号线覆盖主要景点，刷码乘车
- 市区打车起步价9元
- 去棋盘山建议自驾或坐公交168路

### 【住宿建议】

- **首选**：沈河区中街/故宫，景点集中+商业旺
- **次选**：和平区太原街/西塔，韩餐+交通
- **经济型**：铁西区/浑南区，性价比高

## 💡 避坑指南

### ✅ 建议
1. 沈阳故宫早上8:30入园，避开旅行团
2. 西塔烧烤街晚上去，夜生活氛围最佳
3. 洗浴中心选连锁大店，体验标准化
4. 鸡架必吃——沈阳人一年吃掉的鸡架可绕地球N圈
5. 老四季烧烤随便点，鸡架是老雪标配

### ❌ 避雷
1. 景区门口特产店价格虚高
2. 出租车司机推荐的餐厅可能有回扣，自行查点评
3. 冬天室外极冷，注意保暖+手机贴暖宝宝
4. 中街主街小吃价格比巷子里贵30%
5. 张氏帅府编外导游可能收费混乱
