## 🏙️ 城市灵魂

**贵阳：三天不吃酸，走路打蹿蹿。**
西南的山窝里，酸辣是骨子里的信仰。清晨一碗牛肉粉唤醒灵魂，深夜一锅酸汤鱼慰藉肠胃。避暑之都的烟火气，藏在巷弄深处。

## 🍖 地区特色美食 · 贵阳

> 🗺️ 概览：贵州的酸辣在这里浓缩成一碗肠旺面，折耳根的腥香是本地人的味觉暗号，而花溪牛肉粉则是贵阳人晨间最温柔的乡愁。
> 💡 本地人口味特点：— 酸辣为主，无辣不欢；折耳根是灵魂伴侣；酸汤是贵州饮食的底色
> 📖 饮食文化简述：贵阳地处黔中，是贵州全省风味的汇聚之地。"三天不吃酸，走路打蹿蹿"——酸汤不仅是调味品，更是贵州人的生活信仰。

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **甲秀楼** → 晚上亮灯后，南明河夜景
- [ ] **酸汤鱼** → 午餐/晚餐，贵州名菜初体验
- [ ] **黔灵山公园** → 早上，看猴子+祈福

### 【推荐】选 3-5 个

- [ ] **青岩古镇** → 半天，明清古镇+猪脚
- [ ] **花溪公园** → 下午，田园风光+贵阳慢生活
- [ ] **丝娃娃** → 午餐/下午茶，贵阳特色小吃
- [ ] **花溪牛肉粉** → 早餐，贵阳早餐代表
- [ ] **合群路夜市** → 晚饭后，本地人夜宵圣地

### 【可选】有时间加

- [ ] 贵州省博物馆（半天）
- [ ] 天河潭溶洞（一天）
- [ ] 高坡云顶草原（半天）
- [ ] 黄果树瀑布（一天，安顺市）

### 【交通建议】

- 市区景点地铁1/2号线可达，花溪方向公交
- 去青岩古镇有直达公交，也可打车
- 天河潭建议自驾或一日游团

### 【住宿建议】

- **首选**：南明区甲秀楼/大十字，小吃集中+交通便利
- **次选**：云岩区黔灵山附近，老城区+美食多
- **经济型**：花溪区大学城，便宜+安静

## 💡 避坑指南

### ✅ 建议

1. 贵阳\"天无三日晴\"，随身带伞
2. 酸汤鱼选本地人多的店，旅游团的店味道差
3. 青岩古镇猪脚必吃，认准\"王万妈\"等品牌
4. 丝娃娃要蘸酸汤吃，干吃没意思
5. 贵阳夏天是避暑之都，7-8月比外地凉快10℃
6. 牛肉粉选排队的，贵阳人嘴刁

### ❌ 避雷

1. 景区门口土特产店价格虚高，去超市
2. 出租车司机推荐的店可能有回扣
3. 网红店排队超过1小时——贵阳好吃的遍地都是
4. 冬天湿冷，没有暖气，比北方还冷
