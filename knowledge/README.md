## 目录结构

```
knowledge/
├── china/
│   ├── cities/          # 城市知识包（按省份/国家组织）
│   ├── food/            # 地区特色美食
│   ├── culture/         # 本地文化与民俗
│   ├── travel/          # 旅行经验和攻略方法
│   └── avoid/           # 避坑指南
├── international/       # 海外城市知识包
└── common/              # 跨城市通用知识
    ├── packing/         # 行李清单
    ├── health/          # 健康指导
    └── seasonal/        # 季节指南
```

## 城市包模板

- 国内城市：使用 `knowledge/china/cities/_template.md`
- 国际城市：使用 `knowledge/international/_template.md`

模板包含：城市灵魂、速览表格、9维度美食、经典景区、推荐店铺、模块化路线、避坑指南。

## 贡献规范

| 步骤 | 操作 |
|------|------|
| 1 | Fork 仓库 |
| 2 | 复制模板到对应目录 |
| 3 | 按模板结构填写 |
| 4 | 提交 PR |
| 5 | 审核通过后合并 |

### 质量要求

- ✅ 信息准确（标注数据来源/时间）
- ✅ 不编造店铺/地址
- ✅ 避免过度主观（"最好吃"→"本地人认可度高"）
- ⚠️ 时效性强的内容标注有效期
