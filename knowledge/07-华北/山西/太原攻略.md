## 🏙️ 城市灵魂

**太原：一座把面食刻进基因的重工业城市。**  
早上来碗"头脑"配烧麦，中午削面就过油肉。这座山西低调的省会，2500年建城史，煤炭与钢铁的底蕴下藏着精深的面食文化和古朴的晋阳遗风。

## 🍖 地区特色美食 · 太原

> 🗺️ 概览：世界面食看山西，太原把面食做成了一门艺术
> 💡 本地人口味：酸香并重，老陈醋是灵魂，"无面不欢"

### 📝 美食文化笔记
- **餐桌礼仪**：吃饭不可剩饭碗底；醋壶在自己面前，不可用筷子指向
- **节日食俗**：初一饺子初二面，初三人日吃煎饼；腊八粥用八种以上果料
- **生活讲究**："早擦（头脑）午面晚肉"——太原人的饮食节奏；醋是山西人的命根子

## 🗺️ 路线参考（模块化清单）

### 【必做】选 2-3 个

- [ ] **晋祠** → 上午去人少，找讲解员
- [ ] **山西博物院** → 周一闭馆，其他时间均可
- [ ] **喝一碗"头脑"** → 郝刚刚/认一力，太原灵魂早餐

### 【推荐】选 3-5 个

- [ ] **柳巷逛吃** → 下午+晚上，面食/炸鸡/灌肠
- [ ] **汾河公园** → 傍晚散步看夜景
- [ ] **双塔寺** → 春天牡丹花期，平时也可
- [ ] **中国煤炭博物馆** → 带孩子必去
- [ ] **蒙山大佛** → 春天/秋天
- [ ] **太原古县城** → 晚上看灯/拍夜景

### 【可选】有时间加

- [ ] 崛围山红叶（深秋半天）
- [ ] 太原植物园（半天）
- [ ] 晋阳湖骑行（半天）
- [ ] 纯阳宫+文庙（1-2小时）
- [ ] 西山矿区铁锈摄影（半天）

### 【交通建议】

- 地铁2号线贯穿南北（晋祠方向需打车）
- 晋祠/蒙山打车约30-40分钟
- 市区景点公交/地铁覆盖
- 晋阳湖建议自驾或地铁+打车
- 西山矿区建议打车

### 【住宿建议】

- **首选**：迎泽区五一广场/柳巷，美食集中交通便利
- **次选**：小店区万象城/长风，现代舒适
- **经济型**：杏花岭区老城区

## 💡 避坑指南

### ✅ 建议
1. 晋祠请讲解员，否则看不懂
2. 头脑（八珍汤）别加卤，刘/关公吃法
3. 老陈醋认准宁化府/东湖，超市勾兑醋
4. 山西博物院提前公众号预约，周一闭馆
5. 刀削面趁热吃，凉了变硬

### ❌ 避雷
1. 出租车不打表——太原网约车更方便
2. 晋祠门口"野导游"——官方讲解员最可靠
3. 柳巷景区价小吃——巷子里本地人吃的便宜一半
4. 夏天去蒙山——暴晒无遮挡，秋天去
5. 重工业城市空气污染——敏感人群关注AQI
